# FitOS Android app (source)

A small WebView app that wraps the FitOS web app (`app/src/main/assets/index.html`) and adds phone features:
automatic step counting, GPS tracking, reminders, a home-screen widget, barcode camera access and daily backups.

The ready-to-install app is at [`../download/FitOS.apk`](../download/FitOS.apk).

The signing key is **not** in this repository on purpose. Keep `fitos.keystore` private.
